# 視覺識別規範（Lumori 風格）與網頁改版規劃

> **用途**：把 Sean 簡報〈Lumori 價值主張〉的視覺風格整理成一份 CIS，之後拿來改 `domain-design-web` 的樣式、切版與設計。
> **狀態**：規範與規劃，四個問題已決定（第九節）；網頁還沒改（2026-11-09）。
> **依據**：私人 repo `Sean會議記錄/20260930/chapter01_Lumori價值主張/` 的 15 張投影片（主要看 `01_封面`、`03_案例`、`06_八個步驟`、`12_優勢二`、`15_最終優勢`）。色碼是從投影片圖檔取樣後再調整，取樣值和建議值分開列；本文件不放投影片的文字內容。

---

## 一、整體印象

| 特質 | 投影片的做法 | 套到網頁時的意思 |
|---|---|---|
| 輕 | 白底，角落有很淡的藍、蜜桃色光暈；大量留白 | 背景白或接近白，不用滿版色塊 |
| 清楚 | 深海軍藍粗體大標、灰色導言、一種強調藍 | 一頁只有一個最大的標題，層級靠字重與大小，不靠框線 |
| 有秩序 | 固定位置：左上品牌小標、右上頁碼、右側直排英文註記；左邊界一致 | 頁首、側欄、主區塊位置固定，每頁同一套格線 |
| 柔和 | 卡片淡彩底、細邊、柔陰影、圓角大 | 拿掉現行的粗黑框、硬位移陰影 |
| 分類靠色相 | 八個步驟各有一個顏色（藍、靛、青綠、橘、紫、蜜桃、天藍、洋紅），只用在編號、圖示、淡底 | 顏色表示「哪一類」或「什麼狀態」，正文永遠是深藍或灰 |

一句話：**白底、深藍字、一個藍色重點、淡彩分類、柔光點綴。**

---

## 二、標誌與品牌字

1. **字標**：全大寫、極寬字距（約 0.35em）、幾何無襯線。字母 L U M R I 不是純色，由上往下從鋼藍 `#23446E` 漸層到近黑 `#020517`（漸層集中在上半）。字母 O 換成一圈漸層圓環：上方藍 `#8CBEEF`、右側淡青 `#AED4EA`、下方蜜桃 `#F3C89A`，是整套唯一的品牌圖形。
2. **副標**：英文細字、字距約 0.2em、中灰色，放在字標正下方。
3. **小標用法**：每頁左上角都有小號字標（約 13px、字距 0.3em、灰色），不是彩色 logo。
4. **漸層的使用範圍**：只出現在字標的 O、封面標題第二行（藍 → 長春花紫）、背景光暈。內容卡片、按鈕不用漸層。

**網頁怎麼用**：頂列左邊用 Lumori 字標（含 O 圓環），下方子標題「Domain 設計」（第九節 Q1）。

### 3.3 分類色（八步驟色）

每個顏色有三種用法：**實色**（編號數字、圖示）、**淡底**（卡片底）、**深字**（要在淡底上放小字時用）。投影片八個步驟依序如下：

| 步驟 | Token | 實色（取樣） | 淡底（取樣） | 網頁建議用在 |
|---|---|---|---|---|
| 01 | `--c-blue` | `#4898FC` | `#EFF6FE` | ① 範圍 |
| 02 | `--c-indigo` | `#5484F8` | `#EFF4FF` | ② Entity |
| 03 | `--c-teal` | `#20CCAC` | `#F0FCFC` | ③ 流程 |
| 04 | `--c-orange` | `#FC9454` | `#FEF6F2` | ④ 規則 |
| 05 | `--c-violet` | `#904CF8` | `#F2EDFD` | ⑤ 對照 |
| 06 | `--c-peach` | `#FC9C58` | `#F9F3EF` | 和 04 太像，網頁不用 |
| 07 | `--c-sky` | `#388CFC` | `#E4F2FE` | 和 01 太像，網頁不用 |
| 08 | `--c-magenta` | `#E028FC` | `#F8EEFA` | ⑥ 驗證 |

注意：
- 投影片的分類色只靠色相區分（01 與 07、04 與 06 幾乎一樣）。網頁的六步各用一色時，**一定同時寫出編號**，不能只靠顏色。
- 實色在白底的對比多半低於 4.5，不放小字；小字用同色相的深色（例：青綠 `#12866F` 4.5、橘 `#B65A1E` 4.7、紫 `#7A4FE0` 5.2）。

### 3.4 語意色（狀態）

投影片用 ✓（青綠圓）、✕（珊瑚紅圓）、⚠（紅）、圓點清單（各分類色）。網頁現在有「輪到你／提示／完成」三種狀態，對應如下：

| Token | 圖形色 | 淡底 | 小字色 | 投影片取樣 | 網頁意思 |
|---|---|---|---|---|---|
| `--ok` | `#18BCA0` | `#E6F8F4` | `#12866F` | ✓ `#18BCA0` | 完成、凍結、通過 |
| `--turn` | `#FC9454` | `#FFEFE4` | `#B65A1E` | 步驟 04 `#FC9454` | 輪到你（取代現行亮橘 `#FF7A1A`） |
| `--hint` | `#E8B88C` | `#FDF4EA` | `#8A5A1E` | 勾選 `#E8B88C` | 提示、支線（取代現行亮黃；投影片沒有黃色） |
| `--bad` | `#F07080` | `#FEE7EF` | `#C23A50` | ✕ `#F87480`、錯誤卡 `#FEE7EF` | 錯誤、不通過、擋下 |
| `--busy` | `#3388F0` | `#E2F1FE` | `#2470D8` | — | AI 進行中（用主色，靠動畫區分） |

狀態一律「顏色＋圖形或文字」一起出現（✓、✕、圓點＋字），不只靠顏色。

## 五、版面與格線

投影片每頁的骨架（以 1536×1024 換算）：

```
┌───────────────────────────────────────────────┐
│ LUMORI（小標）                         5 / 8  │  ← 頁首：左品牌、右頁碼
│                                       FROM    │
│ 05  章節名稱（藍）                    REALITY │  ← 右側直排註記＋細線
│ 大標（深藍、極粗）                     │      │
│ 導言兩行（灰）                         │      │
│                                               │
│ ┌────┐→┌────┐→┌────┐→ …                    │  ← 內容：卡片列或左右對照
│ └────┘ └────┘ └────┘                        │
│ ┌─────────────────────────────────────────┐   │
│ │ 💡 關鍵觀念   一句藍字結論＋一行灰字      │   │  ← 底部結論橫條
│ └─────────────────────────────────────────┘   │
└───────────────────────────────────────────────┘
```

| 項目 | 投影片 | 網頁建議 |
|---|---|---|
| 左右邊界 | 約 5%（78px） | 主區塊 `padding-inline: max(24px, 4vw)`，最大寬 1120px |
| 區塊間距 | 標題區 → 內容約 40px；卡片之間 16～24px | 間距階：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 |
| 標題區 | 章節號＋小標 → 大標 → 導言，三層 | 每一頁都用同一個「頁首區」元件 |
| 對照版型 | 左邊 ✕ 錯誤做法（粉紅淡底），右邊 ✓ 正確做法（藍淡底），中間大箭頭 | 審查頁的「做法 → 結果」選項、修改前後對照 |
| 流程版型 | 一排等寬卡片＋細箭頭，每張頂端編號 | 首頁六步、切片步驟列 |
| 結論橫條 | 全寬、淡藍底、左圖示、一句藍色粗字 | 每頁最上面的「AI 要你做什麼」 |

| 元件 | 樣式 | 網頁對應的現行元件 |
|---|---|---|
| 卡片 | 白或淡彩底、1px `--line` 邊、圓角 16px、陰影 `0 1px 2px rgba(11,21,51,.04), 0 8px 24px rgba(11,21,51,.06)` | `.card`（現行 2px 黑框） |

| 主要按鈕 | `--accent-strong` 底、白字、圓角 12px、無邊、柔陰影；按下時加深，不位移 | `.btn.primary`（現行硬陰影） |

| 側欄 | `--bg-soft` 底、選中項 `--accent-soft` 底＋`--accent-strong` 字 | `.side-nav`、`.nav-a.on`（現行紫底白字） |

## 七、不要做的

1. 不用粗黑框、硬位移陰影、虛線框當主要樣式（這是現行「任務板」風格，和 Lumori 衝突）。
2. 分類色只用在編號、圖示、淡底，不當正文顏色，不當大面積實色底。
3. 漸層全站最多：字標 O、首頁一行標題、背景光暈；其他地方不用。
4. 一個畫面同時出現的分類色不超過四種（六步列除外）。
5. 狀態不只靠顏色（見 3.4）。
6. 不放投影片的圖片或文字內容；只借視覺規則。
