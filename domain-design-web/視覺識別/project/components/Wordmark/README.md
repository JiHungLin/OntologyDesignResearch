# Wordmark

頂列與封面用的 Lumori 字標：全大寫、字距 0.35em，O 是天藍到蜜桃的漸層圓環，下方一行子標題「Domain 設計」。

- 提供：子標題文字（網頁固定寫「Domain 設計」）。
- 頂列用標準尺寸（字 20px）；首頁或登入畫面用 `lg`（56px）。
- 字母用 `wordmark-top` → `wordmark-mid` → `wordmark-bottom` 的上下漸層（深色主題是白到淡藍灰）。
- O 圓環一圈漸層：上 `ring-sky`、右 `ring-mist`、下 `ring-peach`；不換色、不加陰影。
- 這是依簡報封面用字型重現的字標，不是正式標誌檔；拿到 Sean 的向量檔後換成檔案。
