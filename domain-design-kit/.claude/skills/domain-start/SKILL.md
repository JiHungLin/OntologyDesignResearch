# 建立新切片

參數：`$ARGUMENTS`（第一個字是切片代號，其餘是情境）。

1. **檢查代號**：英文小寫、以 `-` 連接（例：`leave-backfill`）。`slices/<代號>/` 已存在就停下來，改用 `/domain-status`。
2. **確認切片大小**：依 `docs/01` 0.3，情境要是「一個起點走到一個可驗證的業務結果」，不是功能選單。不符合時，提出拆法或改法，請人決定後再繼續。
3. **初始化共用核心**：`core/` 不存在時，把 `templates/core/` 複製成 `core/`（第一條切片）。
4. **建立切片資料夾**：把 `templates/slice/` 整個複製到 `slices/<代號>/`，並把所有檔案中的 `{{切片}}` 換成代號。
5. **確認輸入**：列出 `inputs/<代號>/` 與 `inputs/shared/` 的檔案。沒有 `inputs/<代號>/` 時，請人提供訪談紀錄或既有 User Story 的位置，或明確說「沒有，從零開始」。
6. **詢問人**（一次問完）：
   - 這條切片要做到哪裡、明確不做什麼？
   - 有沒有 Domain 專家或客戶端使用者可以確認？是誰？
   - 依賴但這次不實作的東西，要用什麼靜態替代？
7. 拿到回答後，執行 `/domain-step 1 <代號>`。
