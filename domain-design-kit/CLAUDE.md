# Domain 設計工作規則

這個 repo 用來把一個 domain 從現實轉成數位系統的設計。你（AI）負責**產出**交付物；人負責**審查與決定**。每一步產出後停下來，等人審查並下達凍結，才進入下一步。

你沒有之前對話的記憶。**每次開始工作，先執行 `/domain-status`**，從檔案重建目前狀態，不要猜。

## 三個名詞（使用者不一定熟悉，需要時用這個說法解釋）

| 名詞 | 意思 | 例子 |
|---|---|---|
| 共用核心（`core/`） | 所有已定義的概念，大家共用一份——**成果** | Person、Employment、LeaveEntitlement |
| 領域 | 一個業務主題範圍，用來分類——**範圍** | 人資／請假、人資／薪資 |
| 切片 | 一個情境從起點走到可驗證的結果——**工作單位** | 急診沒去 → 事後補單 → 餘額與扣薪正確 |

不先設計整個領域，而是一條一條切片做；切片怎麼切，先用 `/domain-plan` 和使用者一起討論出切片地圖（`slices/PLAN.md`）。使用者不需要事先知道切片的名稱和範圍。

## 目錄

- `inputs/`：原始輸入（訪談紀錄、既有 User Story、法規原文）。已存在的檔案不修改；使用者在對話中貼上的資料，新增為 `inputs/` 下的新檔案，檔頭註明「使用者於對話中提供，<日期>」。
- `templates/`、`docs/`、`tools/`：唯讀，不修改。
- `core/`：共用核心（Ontology）。只在 `/domain-freeze` 時寫入。
- `slices/PLAN.md`：切片地圖。
- `slices/<切片代號>/`：每條切片的交付物。
- `.build/`：工具用 YAML，由你從 Markdown 轉出，不手改、不提交。

## 必須遵守

1. **格式**：交付物一律照 `templates/` 與 `docs/02` 的格式。欄位值只用 `docs/02` 列出的選項，標記只用 `docs/02` 第三節的寫法。
2. **停下來**：每一步產出後，把狀態改為「待檢查」，向人報告後停止。不要自己進入下一步。
3. **不代替人**：
   - 不填「審查者確認」欄，不寫「結論：通過」，不把狀態寫成「已凍結」（只有 `/domain-freeze` 可以）。
   - 不計算、不填寫黃金案例的「預期結果」「計算過程」「計算者」。
   - 不簽核第 ⑥ 步。
   - 不把自己想出來的驗收問題標成「Domain 專家」或「客戶端使用者」來源；那是 `AI`。
4. **來源**：你提供的法規條號與數字，一律標 `[未核對]`。
5. **留紀錄**：修改狀態為「待檢查」或「已凍結」的檔案時，同時在該切片的 `CHANGELOG.md` 最上面新增一筆。不刪改 `CHANGELOG.md` 的舊紀錄。
6. **語意層不談實作**：第 ①～④ 步的交付物不出現資料表名、欄位名、API 路徑。模型元素用英文識別名稱，第一次出現附中文。
7. **共用核心只有一份**：先查 `core/`，有就引用，不重新定義；要改已驗證的項目，走變更提案。
8. **不確定就問**：範圍、取捨、要不要回頭，提出選項與你的建議，讓人決定。需要專家回答的，寫進 `questions.md`（EQ 編號），相關項目標 `[待專家確認: EQ-nnn]`，繼續往下做。
9. **git**：只有 `/domain-freeze` 會 commit 與打 tag。其他時候不 commit、不 push。

## 指令

| 指令 | 用途 |
|---|---|
| `/domain-status [切片]` | 從檔案重建目前狀態：各步驟狀態、tag、待回覆的專家問題、下一步 |
| `/domain-plan [粗略的範圍或新資訊]` | 建立或更新切片地圖：一起討論有哪些切片、屬於哪個領域、先做哪條 |
| `/domain-new-slice [切片代號或描述]` | 從地圖挑一條切片，建立資料夾，開始第 ① 步 |
| `/domain-step <1-6> [切片]` | 執行某一步：產出 → 挑錯 → 修正 → 自評 → 停下等審查 |
| `/domain-freeze <1-6> [切片]` | 人審查通過後凍結：寫 CHANGELOG、打 tag、合併進 `core/` |
| `/domain-expert-reply <EQ-nnn> <答覆>` | 處理專家回覆：比對影響、提出回頭方案 |
| `/domain-change <描述>` | 切片通過後發現特例或錯誤：判斷等級 0～3 並處理 |
| `/domain-check [切片]` | 轉出 `.build/` YAML，跑檢查工具與引用檢查 |

## 語言

交付物以繁體中文撰寫；識別名稱、代碼用英文。
